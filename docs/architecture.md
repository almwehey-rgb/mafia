# Source responsibilities

Edit `src/client` and `src/server`; `dist/game.js` and
`supabase/functions/mafia-room/index.ts` are generated by `npm run build`.
`src/build-manifest.json` defines deterministic assembly order. `build-sources.mjs
--check` detects an unbuilt edit. The one-time source split preserved exact
runtime SHA-256 hashes before refactoring action handlers.

| Area | Responsibility |
|---|---|
| client/state, transport, session-storage, session-recovery, polling | Session state, network boundary, recovery and synchronization |
| client/host-entry, host-preferences, host-view, host-actions | Host UI and orchestration |
| client/player-view, player-actions, player-tools, player-chat | Player UI, selected actions, dialogs and communication |
| client/role-definitions, role-cards | Role explanation and on-demand artwork |
| client/phase-ui, view-helpers, journey-ui | Shared presentation and notices |
| server/runtime, database, data-access | Per-request scope and database access |
| server/authority, state | Authentication, rate limits, authenticated state reads |
| server/router | Parse/validate requests, authority/generation guards, dispatch |
| server/routes/* | 48 independently named action handlers with explicit context |
| server/transition-plan, commit | Isolated transition planning and atomic commit |
| server/resolution, role-rules, bots, statistics | Outcomes, rules, automated choices and statistics |
| server/views | Authorized response projection; privacy boundary |
| server/telemetry, scripts/monitor-rules | Structured events and alert evaluation |

This is a build-time module split. The browser bundle retains its shared lexical
scope and function names for existing inline event handlers; the server bundle
retains shared data-access helpers. It does not claim full dependency isolation
or an ES-module conversion. Per-action functions receive explicit context and
preserve the original block scope. Further conversion can happen independently
without adding startup HTTP requests.

Extraction was verified in stages: state read optimization, byte-identical
source splitting, action-handler extraction, then full regression tests. No SQL
schema or game-balance change is required by this performance/operations work.
