# UI consistency polish

Implemented locally in dist; not deployed.

- Shared currentColor SVG outline icons with preserved localization sources. Existing self-localized sections keep their own language handling.
- Unified 44px utility controls and gold/dark button styling, with muted red destructive actions and light-mode colors.
- Player will, report and chat controls now have visible labels and flow below the role card, with a normal-flow fallback when no card is present.
- Gold unlocked achievements and gray locked achievements.
- Asset versions and service worker cache updated to v63.

Validation: ui-polish-browser.mjs passed 18 views across 320, 390 and 1280px without horizontal overflow or browser errors. Will/report dialogs, Arabic-English-Arabic switching, retained icons and light mode passed. Existing discussion-display and join-feedback tests passed (2/2).

Browser command: set PLAYWRIGHT_MODULE to the installed playwright/index.mjs and run node tests/ui-polish-browser.mjs. The fixture serves local files and blocks external requests.
