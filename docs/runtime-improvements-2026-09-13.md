# تحسين الأداء والتشغيل المحلي — 2026-09-13

- أصبحت استجابة Service Worker تصل دون انتظار الكتابة إلى الكاش، مع إبقاء
  عملية الحفظ حية باستخدام `waitUntil`. فشل فتح الكاش أو قراءته أو امتلائه
  لا يمنع الاستجابة من الشبكة. ما زالت الصور تستخدم الكاش أولًا، والسكربتات
  الشبكة أولًا، وطلبات API خارج الكاش.
- يتحقق محمل الأدوات الاختيارية من تهيئة الدالة بعد تنزيل السكربت؛ عند فشل
  التهيئة يعرض رسالة ويتيح المحاولة مجددًا بدل الدخول في استدعاء متكرر.
- يعيد `npm run dev` وسكربت PowerShell المحلي بناء القالب والتنسيق قبل التشغيل.
- الأمر `npm run test:performance` يفحص الكاش وتحميل الأدوات الاختيارية.

## التحقق

- نجحت مجموعة اللعبة الأساسية: 88 اختبارًا.
- نجحت أربعة اختبارات لمحمل الأدوات: الطلبات المتزامنة، إعادة تنزيل فاشل،
  غياب التهيئة، وترتيب اعتماد QR.
- نجح فحص الكاش، بما فيه محاكاة كتابة معلقة وفشل التخزين والقراءة وامتلاء الكاش.
- نجح بناء الواجهة وفحص صياغة ملفات JavaScript المعدلة.
- شُغّلت قاعدة الاختبار المحلية عبر `scripts/local-server.ps1`، وتحقق المتصفح
  من تسجيل دخول المضيف وإنشاء غرفة وإظهار باركود الأدمن. سجل المتصفح خالٍ
  من الأخطاء والتحذيرات وقت الفحص. استُخدم المتصفح المدمج لغياب agent-browser.

هذه النتائج محلية؛ لم يُنفذ نشر أو قياس جديد لأداء الإنتاج. إزالة انتظار
الكتابة مثبتة باختبار سلوكي، وليست نسبة تحسن مقاسة لسرعة تحميل الصفحة.

رابط التشغيل: http://127.0.0.1:4173/game، ورمز المضيف التجريبي `12345678`.
قاعدة التجربة في الذاكرة وتُحذف بياناتها عند إيقاف الخادم.
