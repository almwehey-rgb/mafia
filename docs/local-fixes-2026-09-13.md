## التحقق

- 88 اختبارًا ناجحًا، صفر فشل، صفر تخطي؛ السجل `../review-tests-fixed.log`.
- اختبار البطاقات: جميع الأدوار الـ14، وثلاثة مقاسات (390×844، 844×390، 1280×900)،
  تحميل الصور والقلب ولوحة المفاتيح واستمرار الحالة عند إعادة العرض، دون pageerror.
- اختبار المتصفح المتصل بالقاعدة المحلية: دخول المضيف، إنشاء غرفة، انضمام لاعبين
  بجلسات مستقلة، توزيع الأدوار، عرض بطاقة اللاعب، التأكيد، بدء الليل بمؤقت 60 ثانية،
  ثم حسم المرحلة وعرض النتيجة.
- فحص Bootstrap يتحقق من تفعيل RLS، رفض قراءة anon، وإتاحة القراءة لـservice_role.

التحقق محلي باستخدام PGlite ومعالج Edge الفعلي مع ناقل SQL اختباري. لا يمثل اختبار
نشر Supabase أو شبكة PostgREST أو مباراة بأجهزة فعلية متعددة. لم تتغير قاعدة الإنتاج.
الخادم المحلي مؤقت في الذاكرة؛ يفقد بيانات التجربة عند إيقافه. خطوات التشغيل في README.
